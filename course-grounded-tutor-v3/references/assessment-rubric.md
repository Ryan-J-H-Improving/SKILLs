# Assessment Rubric

Read the exercise and advancement protocol before judging any learning or review answer.

## Pre-Marking Coverage Audit

For each requested answer action, compare its required terms, relationships, formula operations, representation, and cognitive demand with what was actually explained and demonstrated. Use the validated blueprint and the teaching turn, not the tutor's previous confidence label.

Classify each action as:

- `Valid learning attempt`: all dependencies were taught and demonstrated at the demanded level.
- `Valid scored attempt`: the user explicitly requested scoring, a scored diagnostic, or an exam simulation and all mode conditions are met.
- `Not counted - tutor coverage gap`: at least one dependency, operation, transition, or visual interpretation was not adequately taught.

For a tutor coverage gap, withdraw the item, repair blueprint and state, teach the missing dependency, and use one different targeted item. Do not add a learner weak point.

## Learning-Mode Marking

- Diagnose without a numeric score unless the user requests one.
- Mark each answer action as correct, conceptually incorrect, essentially incomplete, or correct with a harmless expression issue.
- Judge the reasoning actually evidenced. Do not promote an entire knowledge point from a correct answer covering only one consequence.
- Correct harmless spelling, grammar, wording, or notation inline when the intended course meaning is clear. Do not deduct, block progress, or record a weakness.
- If all planned actions are valid and correct with no unresolved uncertainty, mark the point practiced and automatically begin the next point.
- If the user explicitly skips the exercise, preserve the point as taught without valid practice evidence.

## Exam-Review Marking

- Mark strictly and give a score when marks are known or reasonably assignable.
- Award marks only for reasoning and steps actually present.
- Penalize wrong formula selection, missing assumptions, unsupported interpretation, and notation errors that would confuse a marker.
- Permit questions before teaching only for an explicitly labeled cold diagnostic or exam simulation.

## Feedback Format

For substantial exam answers:

```text
Result: Partially correct
Score: 3/5

What you got right:
- ...

Where marks were lost:
- ...

Correction:
- ...

Targeted replacement:
- ...
```

For ordinary learning, omit the score and keep feedback proportional. Correct answers need only a concise confirmation before the next point begins.

## Targeted Remediation

- Wrong formula choice: test the method-selection trigger in a new context.
- Wrong substitution: test the exact symbol-object mapping or operation that failed.
- Wrong interpretation: ask for one contextual conclusion using different values or representation.
- Essential omission: ask only for the missing evidence.
- Repeated error after one repair: ask the user to explain their mental model before correcting again.

Do not repeat the invalid original question or clone its surface structure. A repair explanation alone is not evidence.

## Practice History

Record only durable evidence:

- Point and exercise-set identifier.
- Tested relationships and cognitive actions.
- Difficulty and answer-action count.
- Blueprint and source gate status.
- Whether the worked example was materially different.
- User result and exact relevant wording.
- Issue class: conceptual error, harmless expression issue, omission, tutor coverage gap, or tutor record error.
- Relationship-level evidence gained or still missing.
- Replacement item and result when remediation occurred.

Use this history to prevent shallow repetition and false mastery.
