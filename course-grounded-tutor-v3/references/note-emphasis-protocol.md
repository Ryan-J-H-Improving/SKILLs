# Note Emphasis Protocol

## Purpose

Make notes easier to scan and more likely to be read without making them noisy.

## Allowed Emphasis

Use Markdown emphasis consistently:

- `**Must remember:**` for content the user should actively memorize.
- `**Key idea:**` for the central intuition.
- `**Exam trigger:**` for words or conditions that signal a method.
- `**Common trap:**` for frequent mistakes.
- `<u>Personal warning:</u>` for a mistake the user personally made or nearly made.

Use bold for labels and important short phrases. Use underlining sparingly because it is visually strong and not equally supported by every Markdown renderer.

## Rules

- Emphasize only high-value content.
- Do not bold entire paragraphs.
- Do not mark everything as important.
- Keep formulas complete and in course notation.
- Explicitly say when a point must be memorized for exams.
- Highlight user-specific misunderstandings more strongly than generic warnings.
