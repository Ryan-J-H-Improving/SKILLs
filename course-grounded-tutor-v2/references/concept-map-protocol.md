# Concept Map Protocol

## Purpose

Use concept maps to reduce confusion when a course introduces many new terms. The map should be simple, visual, and useful for review.

## When To Update

Update `notes/concept-map.md` after:

- A terminology-heavy explanation
- A lecture with many new concepts
- A user shows confusion between similar terms
- A user gives a clear correct explanation in their own words
- An exam question depends on choosing between related terms

## Format

Prefer a compact Mermaid `mindmap` plus short term notes. Keep labels short.

Each term note should include:

- Parent concept
- Related terms
- Key features or characteristics
- Role or purpose
- Course notation if any
- User's correct wording when useful
- Do-not-confuse warning
- Source layer: course core, supporting detail, or enrichment
- Source

## Style Rules

- Use the locked note language.
- Keep entries short and direct.
- Use the user's own correct description if it is clearer than a generic definition.
- Do not turn the map into a long outline.
- Preserve course terms and symbols.
- Keep tutor-added bridge vocabulary visibly separate from course-core terms; its appearance on the map does not make it independently examinable.
